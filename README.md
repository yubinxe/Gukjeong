## 운영 소스에 붙이는 방법 (PC에서)

1. 운영 소스 폴더(현재 `vercel deploy`를 실행하는 곳)에 `outlook/`, `api/outlook/`, `test/outlook.test.mjs`를 복사.
2. 운영 소스의 `package.json`이 `"type": "module"`이 아니어도 동작하도록 함수·모듈은 `.mjs`로 작성됨. JSON import attributes(`with { type: "json" }`) 사용 → Node 20.10+ (프로젝트 설정 24.x 충족).
3. 홈 HTML의 핵심 콘텐츠 아래(첫 화면을 밀어내지 않는 위치)에:
   ```html
   <section id="outlook-entry" aria-label="오늘의 분기점"></section>
   <script type="module" src="/outlook/entry.js"></script>
   ```
4. `node --test test/outlook.test.mjs` 통과 확인 → **Preview 배포**(`vercel deploy`, `--prod` 없이)로 확인 → 승인 후 프로덕션.

## 분석 원칙(코드로 강제)

- 근거 없는 수치 금지: 모든 근거에 URL·발행일·기준일·단위·검증 상태·출처 경로. 테스트가 누락을 실패로 처리.
- 확률: 정책 A(검증 모형)만 퍼센트 허용, 모델 종류·학습기간·표본·백테스트·기준모형·보정 기록이 없으면 거부, 기준모형보다 나쁘면 거부. 현재 사례는 정책 C(정성).
- 사후 재구성: `asOf` 이후 **발행된** 자료는 숨김(사건 날짜가 아니라 공개 날짜 기준). 당시 실제 예측 기록과 분리 표시.
- 컨센서스: 기관 원문이 없으면 "없음"으로 표시. 재인용 보도는 원천 하나로 셈.
- 비용: 페이지 요청은 저장된 분석만 읽음 — LLM·외부 수집을 일으키지 않음.

## 화면

- 채널(텔레그램 채널 문법): 채널 머리(판·기준 시각·기사 수) → 고정 메시지(오늘의 한 문장) → 날짜 알약 → 글. 글마다 원문 링크, 보도 흐름(첫 보도→후속), 언론사 수, `묻기`(텔레그램 답장처럼 인용해 질문), `공유`(iOS 공유 시트).
- 순서: 오늘의 한 문장·3줄 → 시세(20거래일 선) → 지금 확산 중 → 오늘의 연결 → 이어지는 사안 → 입법예고·세계가 본 한국·거시 지표.
- 브리핑 도우미(iOS 문법): 넓은 화면은 오른쪽 고정 창, 휴대폰은 아래에서 올라오는 시트(뒤로 가기·아래로 끌어 닫기, 화상 키보드 높이 추적). 답은 글자 단위로 흐르고, 근거 소식은 `S3` 칩 → 누르면 해당 글로 이동. 멈춤·새 대화·추천 질문. 대화는 그날 탭 안에서만 보관(sessionStorage).
- `듣기`: 기기 내 음성 합성(ko-KR)으로 오늘의 브리핑 낭독.
- 해석이 2.5초 안에 오지 않으면 사실 층부터 그리고, 도착하면 채운다. 브리핑 함수가 없는 배포에서는 `/api/dashboard`로 직접 사실 층을 만든다.

## AI 원칙(코드로 강제)

- 모델: `claude-opus-5-5`(Claude API, 공식 SDK). 해석은 effort `medium` + 구조화 출력(JSON 스키마, S번호 열거), 대화는 effort `low` + 스트리밍. 둘 다 서버측 대체 모델(`fallbacks: "default"`, `server-side-fallback-2026-07-01`)을 켜 두어 안전 분류기 거절 시 같은 호출 안에서 다른 모델이 이어받는다.
- 수치: 해석·답에 나온 숫자를 모델에 준 자료와 대조. 해석은 근거 없는 수치가 든 문장을 **싣지 않고** 개수를 공개, 대화는 답 아래에 "확인되지 않은 수치"로 표시.
- 사실/해석 분리: 해석 문장에는 모두 `해석 · AI` 표지. 정당·인물 평가, 매수·매도 권유 금지(프롬프트). 기사 문장은 자료이지 지시가 아님(프롬프트 주입 방어).
- 비용 상한: 해석은 판(새벽·아침·오후·저녁)이 바뀌거나 TTL(30분)이 지나고 상위 6개 사안 구성이 달라졌을 때만 새로 씀(인스턴스 메모 + CDN `s-maxage=600, stale-while-revalidate=3600`). 대화는 오늘의 자료 블록에 프롬프트 캐시 지점, 질문 1,200자·대화 9,000자·`max_tokens` 8,000, IP당 5분 10회.
- 원천 주소는 요청 Host 헤더로 만들지 않음(위조 Host 로 다른 서버의 글을 모델에 먹이는 것 차단). 대화 API 는 같은 출처 요청만.

## 모션 계층 `motion/` (운영 화면 전체)

운영 `app.js` 를 고치지 않고 DOM 변화에 반응하는 증분 계층. 토큰은 `motion.css` 한 곳(`--mo-micro 140ms … --mo-data 900ms`, 가속 곡선 4종), JS 는 읽기만 한다.
- 위쪽 탭 줄: 글자 폭에 맞춘 활성 표시가 이전 탭에서 다음 탭으로 미끄러지고(정렬 오차 0px 측정), 마우스·키보드 초점은 옅은 표시가 따라간다. 직접 URL 진입은 애니메이션 없이 제자리.
- 아래 탭 막대(휴대폰): 활성 윗선이 칸 사이를 이동.
- 머리 막대: 120px 이상 내려 읽으면 이름 막대만 접히고 탭 줄은 남는다(높이를 바꾸지 않고 transform 만 써서 내용이 튀지 않음). 위로 18px 올리면 복귀, 검색 중·대화상자 열림·키보드 초점이 머리에 있으면 접지 않는다.
- 화면 전환: 머리·탭 줄·탭 막대는 고정, 본문만 짧게 떠오른다(View Transitions).
- 순위·목록(이어지는 주요 사안·키워드·신호·분야별 보도량·주요 사안 규모): 다시 그려질 때 같은 항목은 이전 자리에서 새 자리로 미끄러지고(FLIP), 오른 행은 놋쇠·내린 행은 옅은 선으로 잠깐 표시, 막대는 이전 길이에서 늘거나 준다. 교차하는 행은 지면 배경을 깔고 오르는 행이 위로 지나간다.
- 시세 타일: 1분 갱신에서 값이 바뀐 타일만 숫자가 이전 값에서 옮겨 간다(자리수·부호·단위 유지, tabular). 처음 화면에서는 시세 선이 그려지고 24시간 막대가 바닥에서 선다(한 번만, 저장본→실시간 재렌더 때도 끊기지 않게 이어 그림).
- 더보기 시트: iOS 시트 곡선, 뒤 화면 스크롤 잠금, 뒤로 가기로 닫힘(시트 안 링크로 화면을 옮긴 경우엔 그 이동을 지킴).
- `prefers-reduced-motion` 이면 모두 즉시 최종 상태. 숨은 탭에서는 움직이지 않는다.
- 하지 않은 것: 세계 권력 지형(지구본) 내부 카메라·국가 패널, 시장 분석 차트 교차선, 입법·정책·부동산 화면 내부 전환 — 해당 모듈(`atlas.js` 등) 소스를 직접 고쳐야 해 이번 증분 계층 범위 밖.

국회 대수 → 공개 시점 → 지역 → 인물로 내려가는 지도 중심 분석 화면.
- 지도: MapLibre GL(운영 지구본과 같은 5.24 판, 지연 로딩) · 통계청 센서스용 행정구역경계 2018(시도 17·시군구 250, 165KB 위상 구조, 군위군은 현재 대구 소속으로 재집계).
  색은 순차형(숲 → 올리브 → 금, 로그 분위수 6단계)과 발산형(황토 ↔ 중립 ↔ 초록)만 쓰고 정당색·적청은 쓰지 않는다. 0원(보유 신고 없음)과 자료 없음은 다른 색.
  데이터 기반 색은 보간되지 않으므로 두 판을 겹쳐 불투명도를 교차 — 시점을 바꾸면 지도 색이 720ms 동안 옮겨 간다.
- 상호작용: 지역 위에서 경계·이름·값·전국 대비 비중(툴팁은 지도 안에 머문다), 누르면 선택 강조·카메라 이동·그 안의 시군구 분포·패널·순위가 같은 상태로 갱신. 확대하면 시군구, 축소하면 시도. 인물 선택 시 그 사람의 신고 지역만 남기고 카메라를 그 지역 전체에 맞춘다(지도를 처음으로 되돌리지 않음).
- 공개 시점 타임라인: 이전·다음·재생(1×/2×)·눈금 선택·좌우 화살표. 지도 색·전국 합계·지역 순위(FLIP·막대·숫자)·패널이 같은 시점으로 함께 바뀐다. 시점 사이 전환은 화면 효과일 뿐 그 사이 재산 상태가 아니라고 명시.
- 두 시점 비교: 나란히(같은 척도, 카메라 동기화) / 증감만(늘어남·줄어듦·변동 없음·비교 불가), '각 시점 전체' vs '두 시점 모두 공개한 같은 사람'.
- 대수 변화 분해(폭포): 전체 변화 = 같은 의원의 변화 + 새로 들어온 의원 − 떠난 의원, 항등식 확인을 화면에 표시. 실제 자금 흐름이 아니라고 명시. 지역 간 흐름 화살표는 그리지 않는다.
- 집중도: 서울·인천경기·비수도권 비중, 1인당 평균·중앙값, 상위 10% 몫, 정당(기준일 소속)별 표.
- 접근성: 지도와 같은 수치를 표로, 패널·순위는 키보드 조작, 화면 읽기용 설명. 휴대폰은 지도 58vh + 아래 시트(접힘·중간·펼침, 끌어 조절).

이 실행 환경에서 `assembly.go.kr`(국회공보 원문)은 기본 HTTP 클라이언트를 400 으로 막고, 뉴스타파가 올린 원문 사본(DocumentCloud)은 Cloudflare 봇 확인으로 막힌다. 사람의 브라우저가 아닌 것을 위장해 우회하지 않았다.
뉴스타파 데이터는 이용 원칙이 출처표시·비영리·**변경금지**라 집계·재가공 원천으로 쓰지 않는다(참고만).

실데이터 넣는 순서(PC 브라우저에서 원문 PDF 를 받은 뒤):
1. 공개 원문 한 건마다 `officials/raw/<공개일>.meta.json`(공개일·기준일·최초/정기·대수·원문 주소)과 `officials/raw/<공개일>.csv`(원문 표 한 줄 = 한 행: 성명·관계·대분류·세부·소재지·종전/현재가액(천원)·사유·쪽)를 만든다. PDF → CSV 변환은 첫 문서로 표 구조를 맞춰 보는 보정이 필요하다.
2. `node scripts/officials/build.mjs` — 명부 대조(동명이인은 `official_id` 지정 요구), 소재지 → 시군구 매칭(불명확하면 시도까지만), 원문 총계 = 자산 − 채무 대조. **한 사람이라도 어긋나면 그 공개 건 전체를 싣지 않고** `verification.json` 에 남긴다.
3. `npm test` 통과 → 화면이 자동으로 실자료로 바뀐다(합성 자료와 경로가 다르다).

화면 검수용 합성 자료: `/officials/?fixture=synthetic` (`scripts/officials/synthetic.mjs` 생성, 가상 인물·가상 정당, 지도 위 '합성 시험 자료' 표지). 실명 명부와 섞지 않는다 — 테스트가 강제.
